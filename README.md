# NYT Web Scraper

This project is a Python web scraper that extracts the title, author, publication date, and content from a New York Times article URL.

## Usage

Run the script from the command line:

python scrape_newyorktimes.py "ARTICLE_URL"

Example:

python scrape_newyorktimes.py "https://www.nytimes.com/2020/09/02/opinion/remote-learning-coronavirus.html"

## Technologies Used

Python  
Requests  
BeautifulSoup  
JSON parsing
